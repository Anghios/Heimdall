# The file browser no longer closes the application

Install this one. Every version since v2026.090701, released on 7 September, could
close without warning: no message, nothing in the log, no error report. The window
simply disappeared.

## What was happening

The file browser resolves the words it shows you from a translation catalogue. The
small helper that does the lookup called itself instead of reading the catalogue.
Nothing stopped it, so the first status message the file browser produced consumed
the whole of the application's working memory for that task and Windows ended the
process on the spot.

That kind of ending runs no error handler, which is why it left nothing behind to
read. It was not a silent failure to log; there was nothing to log with.

## When it happened to you

Whenever the file browser had something to say, and in practice that meant whenever
connections dropped. Losing several at once was enough: a network adapter changing
underneath the session, or putting the machine to sleep with sessions still open.
The file browser announced the disconnection, and the application closed.

An open file browser tab was enough. It did not have to be the tab you were looking
at, which is why the same crash was seen while working in a remote desktop session.

## Fixes

- The file browser's locale helper reads the catalogue.
- A check refuses any method whose whole body is a call to itself, across the whole
  source tree, so the same mistake cannot be written again anywhere.

## How it was found

From a crash report captured on an affected machine. The record of the failure held
one short sequence repeated 32,040 times, which named the helper directly. Without
that capture the cause would still be unknown: nothing else about this failure is
recorded anywhere.

## What we are not claiming

Two earlier crashes, on 10 and 11 September, were never captured, and nothing here
proves what caused them. What can be said is that this defect was present in the
version they ran, and reachable by exactly the circumstances that were reported.
