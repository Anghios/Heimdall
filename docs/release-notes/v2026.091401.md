# The application no longer closes when every connection drops at once

Heimdall could disappear without a message, leaving only a Windows error box behind
and nothing in its own log. It happened when every transport went down together:
a network adapter recreated underneath the tunnels, or the machine entering sleep
with RDP sessions and SSH tunnels open.

Each of those notifications started a connection attempt from inside the previous
one, and the surface that hosts an RDP session realizes its layout by running the
pending window messages. Nested far enough, the process ran out of stack and Windows
ended it on the spot. That is why there was nothing to read afterwards: a stack
overflow runs no error handler, so nothing was logged and nothing was saved.

Connection attempts that arrive while another one is still preparing its surface now
wait for it to finish instead of starting on top of it.

## Fixes

- Embedded RDP no longer nests its layout passes when disconnections arrive in a burst.
- The waiting is bounded: after ten attempts to find a clear moment, the session
  connects anyway rather than waiting forever.

## Dependencies

- `System.Security.Cryptography.ProtectedData` updated from 10.0.11 to 10.0.12, a patch
  update of the package that protects the local credential store. No advisory is
  attached to it.

## What this does not settle

The exact sequence of calls that consumed the stack was never captured, because
Windows saves nothing for this kind of crash unless the machine was configured in
advance to do so. What is fixed here is the one place in the RDP connection path
where the nesting had no limit, and it matches everything that was observed: the
thread that died, the trigger, and the burst that preceded it. If the same crash
returns on this build, there is a second place, and only a crash dump will name it.

The cost of the change is a delay: a session that asks to connect during a burst
now waits for the surface ahead of it, so reconnecting several panes at once can
take slightly longer than before.
