# Heimdall speaks Spanish

Heimdall has a third language. Every one of its 6370 strings is translated, and
the interface switches to Spanish from the language box in Settings, General,
beside English and French.

The translation was contributed by Néstor (Anghios), who is the first person
other than the author to have work in this repository. The third-party notices
have a Spanish edition too, alongside the English and French ones.

## Two things Spanish does not reach yet

The embedded diagram editor carries English and French resources only, so
draw.io's own menus stay in English on a Spanish profile. Heimdall's own labels
around it are translated.

The passphrase generator builds its phrases from English and French word lists.
A Spanish profile generates English passphrases.

Neither is a defect in the translation, and both are named here rather than left
to be found.

## What a third language cost, and what it bought

Nothing in Heimdall compared one language catalogue against another. Every check
that read them named English and French by hand, which is a reasonable thing to
write when there are two languages and a quiet failure when there are three: the
Spanish catalogue could have shipped complete and been read by none of them.

Four of those checks now read every catalogue that ships, and a new one holds
each translation to exactly the keys English holds, in both directions, with the
placeholders intact. That check did not exist before, in either direction. A key
added to one language alone used to reach the other languages as the key name
itself, printed where the sentence should be, and nothing would have failed.

The language list in Settings is now compared against the catalogues on disk, so
a language nobody can pick and an entry with nothing behind it are both
failures, and the settings validator is held to the same list, so a language
cannot be offered, chosen, and then refused when the profile is saved.

## Contributing

There was no CONTRIBUTING file. The first outside contribution arrived with
nothing in the repository saying how a change is reviewed, or that the quotes
and dashes a text editor inserts by default are refused here. That last omission
was not free: it cost that contribution 183 pairs of the wrong quotation mark,
and no check was reading the file it was in.

There is now a contributing guide, in English and French, covering what the
review looks for, the single command that decides whether a change passes, the
refused characters and why, and a checklist for adding a language.

## Corrections

The feature list said the interface was bilingual and quoted an i18n key count
that had drifted by 98 keys. The security page described a continuous
integration gate enforcing key parity between English and French. That gate did
not exist when the sentence was written. It exists now, across every catalogue,
and both pages say what is actually enforced.

The key count is read out of the catalogue and compared against every page that
states it, so it cannot drift again without something failing.

The development guide quoted a test baseline of 5453 passing tests and 6 skipped
ones. An unfiltered run over the eight test assemblies measures 12833, all
passing, none skipped.
